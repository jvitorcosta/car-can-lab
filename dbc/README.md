# Signals

Confirmed signals, one [DBC](https://github.com/commaai/opendbc) file per car, named
`make_model_year.dbc`, for example `honda_city_2021.dbc`.

A signal belongs here when you have seen it follow the real thing in two separate sessions: a
suspect from one recording isn't confirmed yet. At the top of the file, in comments, say:

- the car: make, model, year, market, engine and gearbox;
- the adapter you used;
- how you confirmed each signal.

This folder is empty so far: no signal has been confirmed on any car yet.
